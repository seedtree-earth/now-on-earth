# Seasonal content for Hearts Now

One file per season (`seasons/`) and per turning of the wheel (`turnings/`). Each holds:

- `description`: a few words on the quality of this time
- `reflection`: one question to sit with, never more than one
- `invitation`: a closing invitation to go outside and notice something of this season
- `status`: `"draft"` or `"reviewed"`, and `reviewedBy`: who reviewed it

Hearts Now uses the turning's file when the year is near that turning, and the season's file the rest of the time. The same file serves both hemispheres: Beltane's words are used whenever and wherever it is the height of spring (early May in the north, early November in the south).

**Review before going live.** Only files marked `"reviewed"` are shown on the public site. Drafts appear on localhost only, tagged "draft". To approve a file, read it, edit as you like, then set `"status": "reviewed"` and `"reviewedBy"` to your name.

**The rules these follow** (see Principles in the main README): no streaks or nudges; every reflection ends with an invitation outside; seasonal cadence, not daily noise; place-specific, not universal. The eight names are the Celtic/European wheel tradition's. Local and Indigenous seasonal knowledge is never written here from published sources; it comes only from its custodians, in partnership, on their terms.

Nothing anyone reflects on is stored. A private seasonal record is for a later version (V4), with its own privacy design.
